**Frontend:**

**Infrastructure:**
- Docker (containerization)
- Vercel/Netlify (frontend deployment)
- Railway/Render (backend deployment)

### **Data Flow**

1. **User Authentication** → Spotify OAuth
2. **Data Collection** → Fetch listening history (last 6-12 months)
3. **Audio Analysis** → Extract features (tempo, energy, valence, etc.)
4. **Pattern Detection** → Time-based listening habits
5. **Personality Mapping** → Audio features → Big 5 traits
6. **Company Profiling** → Aggregate employee patterns
7. **Matching Algorithm** → User profile → Company culture fit
8. **Visualization** → Beautiful, shareable results
