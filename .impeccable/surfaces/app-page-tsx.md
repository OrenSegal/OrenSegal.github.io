# Surface: app/page.tsx (full site — Hero, About, Projects, Contact, Footer, Nav)

Mode: Persuade. Audience: recruiters + technical interviewers, split evenly between a fast skim and a deep read. Job: leave convinced Oren builds trustworthy AI infrastructure, and click into at least one real repo. Proof/content: 8 real shipped GitHub projects (lib/projects.ts), real contact links, no invented metrics. Constraint: Next.js 14 static export to GitHub Pages, no backend, no image generation available (code-led only).

## Direction contract

THESIS: The page is a literal underground utility cutaway — what a visitor sees on the surface sits on real strata of infrastructure work beneath it, echoing the product's own line: "the parts of AI systems that keep them honest... the plumbing." Refuses every document/print genre already tried (status pages, ledgers, patent plates) and the excluded instrument-panel/costume categories.

OWN-WORLD: Near-black ground kept as literal depth; a single vertical cutaway spine runs the page, marking strata in the existing monospace face. Each project becomes a labeled utility line crossing the spine (id, verified date — already real data), accent green marks only the active/expanded line. Flat fields separated by hairline strata boundaries only — no gradients simulating soil, consistent with the One Surface Rule.

STORY: Visitor starts at the surface (hero) → scrolls down through strata into Work, each project a utility line at its depth → clicking a line opens it in place, a tactile reveal, to its full incident-style writeup → About sits as the deepest, plainest layer (maintainer's own note) → Contact surfaces back up as the exit point.

FIRST VIEWPORT: H1 stays; beneath it the depth spine begins with a "surface" tick and the real verified-count line (already built) as the first utility tag below the fold line, setting up the cutaway read before any scrolling.

FORM: Seed key 762239b1, re-roll round 3, assigned index 4 (Urban utility cross-section), user-confirmed via structured choice. Oscilloscope challenger excluded outright as the already-rejected instrument-panel category. Variable-font specimen, telop captions, Bollywood poster, indoor weather-sun all declined, off-tone, no raise. Raised by sneaker-box-wall: expanding a project line into its writeup gets a tactile "open" motion, not a flat accordion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
